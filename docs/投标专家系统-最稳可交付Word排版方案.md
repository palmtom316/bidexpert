# 投标专家系统 ------ 最稳可交付 Word 排版方案（AI 输入版）

版本：release/V1.0\
用途：作为 AI 生成投标文件时的排版与结构约束规范输入

------------------------------------------------------------------------

# 一、总体目标

本规范用于指导 AI 在生成投标文件时：

-   严格遵守 Word 模板样式体系
-   不破坏目录、编号与分节结构
-   不进行复杂排版重构
-   生成内容可直接由 docxtpl 渲染
-   支持 LibreOffice 自动刷新目录并导出 PDF

核心原则：

> 排版结构由模板控制\
> AI 只负责内容生成\
> 程序只负责填充与轻量修整

------------------------------------------------------------------------

# 二、文档结构规范

文档固定为 4 个 Section：

1.  封面（无页码）
2.  目录（罗马数字页码）
3.  正文（阿拉伯数字页码）
4.  附件（可续页码）

AI 生成内容必须归属于"正文"或"附件"部分。

------------------------------------------------------------------------

# 三、标题样式体系

AI 输出的结构必须使用如下层级标记：

-   Title1：一级标题
-   Title2：二级标题
-   Title3：三级标题
-   Title4：四级标题

要求：

-   不得手写编号（如"1."、"1.1"）
-   仅输出纯标题文本
-   编号由 Word 模板多级列表自动生成

示例：

Title1: 项目总体说明\
Title2: 施工组织设计原则\
Title3: 安全管理措施

------------------------------------------------------------------------

# 四、正文样式规范

正文段落统一使用：

-   BodyText
-   BodyText_Indent
-   ClauseText（条款类说明）

禁止：

-   指定字体
-   指定字号
-   使用 Markdown 粗体或 HTML 标签

AI 输出必须为纯文本段落。

------------------------------------------------------------------------

# 五、表格生成规范

AI 仅输出结构化表格数据，不生成表格格式。

JSON 示例：

{ "table_data": \[ {"no": "1", "name": "技术负责人", "value": "张三"},
{"no": "2", "name": "项目经理", "value": "李四"} \] }

Word 模板负责表格样式与边框。

------------------------------------------------------------------------

# 六、图片与附件规范

图片与附件仅输出说明信息：

-   图片名称
-   图片说明文字
-   文件引用标识

实际图片插入由程序完成。

------------------------------------------------------------------------

# 七、目录策略

目录使用 Word 自动目录。

生成后处理方式：

方式 A：人工打开 Word → 全选 → F9 更新目录\
方式 B：LibreOffice headless 自动刷新并导出 PDF

服务器命令示例：

soffice --headless --convert-to pdf file.docx

------------------------------------------------------------------------

# 八、禁止行为

AI 严禁：

-   输出手动编号
-   输出分页符标记
-   输出样式控制代码
-   修改页眉页脚结构
-   输出目录文本

------------------------------------------------------------------------

# 九、推荐生成流程

1.  AI 生成结构化 JSON
2.  docxtpl 渲染 Word 模板
3.  python-docx 轻量修整
4.  LibreOffice 导出 PDF
5.  人工快速校对

------------------------------------------------------------------------

# 十、稳定交付原则

-   模板工程化
-   内容结构化
-   自动化不过度
-   允许人工最终确认

本方案为当前阶段最稳可交付方案。
