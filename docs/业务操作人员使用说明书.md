# BidExpert AI 辅助投标系统 — 业务操作人员使用说明书

> 版本：V1.0 | 更新日期：2026-02-23

## 系统简介

BidExpert 是一套 AI 辅助投标系统，帮助投标团队完成从资料准备到最终投标文件交付的全流程工作。系统通过浏览器访问，左侧导航栏按工作流程分为 6 个模块，从上到下依次操作即可。

## 访问方式

打开浏览器，输入管理员提供的系统地址（通常为 `http://服务器IP:8080`）。首次使用前，需要在右下角"AI 模型设置"中填入管理员提供的 API Key。

## 操作流程（按顺序执行）

### 第一步：投标专家库 — 建立知识底座

这是所有后续工作的基础。将公司过往投标文件、规范、业绩、资质等资料导入系统。

- 推荐流程 — 文档结构化转换：选择 PDF/Word 文件，选择资料类型（过往投标文件/规范/公司业绩/公司资质/管理人员资质及业绩），点击"开始转换并预览"。预览无误后点击"确认入库"。也可直接点击"一键转换并入库"跳过预览。
- 快速通道：对格式稳定、质量已验证的文档，可直接使用"快速入库"，支持多文件同时上传。
- 结构化补录：对无法从 PDF 提取的信息（如特定规范条文、业绩明细），可手动逐条录入。
- 专家库浏览：入库完成后，可在此查看已入库的文档和内容片段，确认数据质量。

### 第二步：招标文件分析 — 读懂招标书

收到新招标文件后，上传 PDF，点击"开始分析"。系统会自动拆解招标文件，提取投标要点、评分标准、合规要求、加分项和风险提示。分析完成后：

- 左侧显示拆解结果卡片
- 右侧显示可编辑的投标要点汇总
- 确认要点后，点击"同步到投标文件编制"传递给下一步

### 第三步：投标文件编制 — 逐章撰写

这是核心工作环节，采用"人机协作"模式：

1. 载入投标要点（或手动粘贴招标要求）
2. 点击"生成目录框架"，系统自动生成投标文件目录
3. 检查目录，确认无误后点击"用户确认并锁定目录"
4. 在左侧目录树选择章节，进入逐章编写：
   - 用户交付内容：填写本章的人工要求、重点表达、禁用词等
   - 检索专家资料：系统从专家库中检索相关内容
   - AI 逐章生成：AI 结合专家库和用户要求生成初稿
   - 章节最终稿：系统合成工作稿，可继续手动调整
5. 确认后点击"章节确认"

可选择不同智能体（内容生成 1/2/3）和并发数量来控制生成质量和速度。

### 第四步：审核评分与定稿 — 质量把关

- 点击"拉取审核"查看整体合规审核结果
- 点击"拉取评分"查看模拟评分
- 对每个章节可执行单独审核，选择"通过/调整后通过/需重写"
- 填写交互备注，点击"应用交互结果"
- 全部章节审核通过后，点击"形成最终投标文件"汇总

### 第五步：排版与终审 — 最终交付

- 选择封面模板（无封面/蓝波/简洁/城市）
- 设置页眉页脚、页边距
- 调整标题和正文的字体、字号、对齐、行距等排版参数
- 填写输出文件名，点击"排版与终审"生成 Word 文档
- 执行终审检查，确认符合性
- 点击"锁定最终交付"完成

### 第六步：投标记录 — 归档管理

投标完成后，记录工程名称、招标单位、投标结果（中标/未中标）、文件信息等，形成历史档案。

### 知识闭环：回灌专家库

终审通过后，建议将最终投标文件回灌到专家库（第一步的"投标文件回灌专家库"功能），让系统越用越聪明。

## AI 模型设置（右下角齿轮按钮）

- 项目 ID 和 API Key：由管理员提供
- OCR 设置：用于文档识别，支持 glm-ocr 和 textin 两种引擎
- 模型 Profile：可配置不同 AI 模型（百炼 Qwen3/OpenAI/DeepSeek）
- 流程绑定：不同工作环节可使用不同模型，如专家库用便宜模型、内容生成用高质量模型

## 注意事项

- 单个文件上传限制 50MB
- 系统会自动过滤涉及报价的敏感内容，防止泄露
- 所有操作都有审计日志记录
- 浏览器中的 OCR 配置仅保存在当前浏览器，换电脑需重新配置
