# 专家库生成优化 V2.0（2026-02-27）

以下为“10个优化点”的代码修订计划（仅计划，不执行）。
批准后按分批顺序实施。

## 总体原则
1. 兼容现有接口，新增能力默认不破坏旧流程。
2. 涉及新表一律走 Alembic 迁移。
3. 每个优化点都有对应 API、UI、测试与审计。

## 1. 质量指标“真实化”落库（替代启发式统计）
- 目标：`schema通过率/字段完整率/回退触发率/人工复核率/证据覆盖率`来自真实检查结果，不是推断。
- 主要改动：
  - 新增表：`kb_quality_check_run`（run级）+ `kb_quality_check_item`（字段/规则级）
  - 入库流程写入每次校验结果与错误码
  - 统计接口改为从质量表聚合
- 影响模块：
  - `app/api/endpoints/stats.py`
  - `app/services/expert_library.py`
  - `app/models/tables.py`
  - `migrations/versions/*_add_kb_quality_check_tables.py`
- 验收：
  - 同一批文档重复统计结果稳定（无随机漂移）
  - API返回可追溯到具体规则ID/错误码

## 2. 人工复核率改为“真实工单闭环”
- 目标：人工复核率基于工单状态，不再只看异常队列。
- 主要改动：
  - 新增表：`expert_review_task`（pending/in_review/approved/rejected/rework）
  - 新增 API：创建、领取、提交、关闭复核任务
  - 看板人工复核率改为：`人工处理过的任务 / 应复核任务`
- 验收：
  - 任意时间窗口可追溯“谁审、何时审、结论”
  - 复核率与任务状态一致

## 3. 失败类型标准化（taxonomy）
- 目标：失败类型可比较、可统计、可治理。
- 主要改动：
  - 定义统一错误码：`RATE_LIMIT/TIMEOUT/SCHEMA_INVALID/JSON_INVALID/OCR_FAIL/...`
  - LLM/OCR/抽取链路统一写码
  - 模型对比接口输出 `top_failure_type` 和 `failure_distribution`
- 验收：
  - 失败统计不再出现自由文本碎片
  - 同类失败跨模型可横向比较

## 4. 双窗口对比改为“互斥窗口”
- 目标：比较更科学（当前窗口与历史基线不重叠）。
- 主要改动：
  - `expert-model-compare-window`改为：
    - current: `[now-days, now)`
    - baseline: `[now-days-baseline_days, now-days)`
  - UI明确显示两个窗口的实际日期区间
- 验收：
  - 两窗口记录集无交集
  - 同参数重复查询结果一致

## 5. 成本从“估算”升级到“实账优先”
- 目标：模型选型基于真实成本。
- 主要改动：
  - 新增表：`llm_cost_ledger`（账单单价、币种、缓存命中、实际费用）
  - 兼容策略：无实账时回退估算
  - 看板同时展示 `actual_cost_usd` 与 `estimated_cost_usd`
- 验收：
  - 有实账数据时，统计以实账为准
  - 成本可按模型/阶段/窗口汇总

## 6. 阈值治理版本化 + 审批 + 回滚
- 目标：阈值发布可管控、可回滚。
- 主要改动：
  - 新增表：`expert_threshold_version`
  - 状态机：`draft -> approved -> published -> rolled_back`
  - 新增 API：创建版本、审批、发布、回滚、查看diff
- 验收：
  - 每次发布有版本号与审批记录
  - 可一键回滚到任意历史已发布版本

## 7. 生成抗幻觉：句级 claim-evidence 门禁
- 目标：无证据句子不能通过最终导出。
- 主要改动：
  - 生成后做 claim 拆分与证据绑定校验
  - 新增门禁策略：`STRICT/BALANCED/OFF`
  - 导出前阻断未绑定证据或冲突证据句
- 验收：
  - 审查报告可列出“未证据化句子清单”
  - STRICT 模式下未过门禁禁止导出

## 8. 黄金集回归评测（持续校准）
- 目标：模型切换/阈值调整有客观回归基线。
- 主要改动：
  - 新增评测集目录与标签规范（样本、标准答案、评分脚本）
  - 新增评测命令与报告 JSON
  - 看板接入最近一次评测摘要
- 验收：
  - 每次策略变更可产出回归报告
  - 至少输出准确率、召回率、幻觉率、证据一致率

## 9. 审计包导出（外部审计可用）
- 目标：项目级“完整可审计证据包”一键导出。
- 主要改动：
  - 新增导出 API：打包策略、阈值版本、模型调用、质量结果、人工记录、门禁结果
  - 格式：`zip + manifest.json`
- 验收：
  - 外部不连数据库也能复盘关键决策链路
  - manifest 中包含哈希与时间线

## 10. 权限分层（RBAC）
- 目标：防误操作、防越权发布。
- 主要改动：
  - 角色：`viewer/operator/reviewer/admin`
  - 高风险操作（阈值发布、模型策略修改、回滚）需 reviewer/admin
  - API 层统一权限校验
- 验收：
  - 越权请求返回 403
  - 审计日志记录权限拒绝事件
